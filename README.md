# Bathtub

Bathtub is a programmatic game framework for the Denison Coding
Club to host competitions.

## Compilation For Linux

- Install sfml (the graphics/sound/input library used)
    - In NixOS this would be `sfml`
- Install dotnet
    - In NixOS this would be `dotnetCorePackages.sdk_10_0-bin`

Then, do `dotnet run` to compile and run.

## Compilation For Windows/VSCode

- Install .. and the the run button in VSCode will just work
